# GitHub básico: primeiros passos e colaboração

**Grupo:** [identificação do grupo]  
**Integrante(s):** [nome(s)]

**Objetivo:** ensinar uma pessoa iniciante a criar um repositório, organizar arquivos, registrar alterações e colaborar usando o GitHub pelo navegador.

## Público-alvo e conhecimentos necessários
Material destinado a quem nunca utilizou o GitHub. É necessário ter acesso à internet, um navegador e uma conta GitHub. Não é necessário instalar Git nem utilizar o terminal.
